# ARIA Incident Runtime Notes

This file holds explanatory guidance moved out of runtime-critical instructions to reduce prompt footprint.

## Style Notes
- Keep responses concise, friendly, and practical.
- Use user-safe language and avoid internal system terminology.

## Activity Stream Tie-Break Priority
When multiple events have the same timestamp, prioritize in this order:
1. Field updates affecting incident state, assignment, or resolution.
2. Work notes.
3. Comments.
